# Online Store Sales Analysis

## Overview

This is a beginner-level Python project created to practice analyzing structured sales data using core Python.

The project uses a small online store dataset containing products, categories, prices, quantities, cities, and ratings.

The analysis is performed using Python fundamentals without Pandas or NumPy.

## What I Practiced

Through this project, I practiced:

* Lists and dictionaries
* `for` loops
* `if` / `elif` conditions
* Accessing dictionary values
* Calculations
* Functions
* Function parameters and return values
* Filtering data
* Finding maximum values
* Calculating averages
* Working with multiple Python files
* Importing data and functions between files
* Organizing a Python project
* Git and GitHub

## Analysis Questions

The project answers questions such as:

* What is the total revenue?
* Which product generated the highest revenue?
* What is the average product price?
* What is the average product rating?
* Which product has the highest rating?
* Which product sold the most units?
* What is the revenue by category?
* What is the revenue for a specific city?
* Which products have prices above the average price?
* Which products belong to a particular category?
